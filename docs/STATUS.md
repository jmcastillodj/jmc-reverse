- M5: Sibilance detection (heuristic DSP, not AI): STFT features (4.5-11 kHz energy ratio, centroid, band flatness, level, hi/lo) computed once at load (Analyzing state); sensitivity only re-runs the threshold stage. Rules: min 40 ms / max 600 ms per region, 20 ms gap bridging, absolute -75 dB gate, and "HF noise throughout" (>55% of frames) => treated as non-vocal. Stereo: each channel analysed, strongest wins (hard-panned and out-of-phase OK). Regions drawn on the source waveform; messages shown when none found (whole source is then used). Manual override: Shift-drag adds, Alt-click removes, Reset edits button. Emphasis (Amount): detected regions get +HF boost, the rest is tucked up to -10 dB before the reverb.
